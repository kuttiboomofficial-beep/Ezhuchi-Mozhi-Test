# Ezhuchi Mozhi — Tamil Status & Quotes

Android app built with Kotlin and Jetpack Compose.

## Included
- 500 Tamil quotes (12 in MainActivity plus extraQuotes in QuoteData.kt)
- Search and category filters
- Favorites saved locally
- Copy and Android share sheet
- Sunset image hero on the home screen
- GitHub Actions workflow for a debug APK

## Build
The GitHub Actions workflow builds a debug APK when code is pushed to `main` or manually triggered.

Package: `com.tavrixlabs.ezhuchimozhi`

Please test the generated APK on a real device before publishing.
